# Universal Commerce Protocol - Agent Guidelines

Welcome! This repository supports AI agents in two primary capacities: contributing to the protocol itself, or implementing the protocol in external systems.

Please identify your task and proceed to the relevant guidelines:

## I am contributing to this repository (UCP Specification/Docs)

If your task involves editing the schemas, modifying the documentation, or working on the core protocol files in this repository, please read and follow:

👉 **[Contributor Agent Guidelines](AGENT_CONTRIBUTOR.md)**

*Use this for: schema edits, documentation updates, local build/validation commands.*

## I am implementing UCP in an application or service

If your task is to build a UCP-compliant node, integrate UCP into a business platform, or use the UCP SDKs, please read and follow:

👉 **[Implementer Agent Guidelines](AGENT_IMPLEMENTER.md)**

*Use this for: understanding message schemas, finding SDKs, learning about schema resolution and conformance.*
