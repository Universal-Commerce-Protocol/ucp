# Protocol errors over MCP

A protocol error is a JSON-RPC error that carries the UCP body in `data`, with the same HTTP status as on REST. Business outcomes arrive in `structuredContent` exactly as in `errors-rest.md`.

Generated by `make check`. Do not edit; run `make update`.

## 1. `search_catalog`

```http
POST /mcp HTTP/1.1
Host: business.example
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "search_catalog",
    "arguments": {
      "meta": {"ucp-agent": {"profile": "https://platform.example/profiles/missing.json"}},
      "catalog": {"query": "poster"}
    }
  }
}
```

```http
HTTP/1.1 424 Failed Dependency
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "id": 3,
  "error": {
    "code": -32001,
    "message": "https://platform.example/profiles/missing.json answered 404",
    "data": {
      "code": "profile_unreachable",
      "content": "https://platform.example/profiles/missing.json answered 404"
    }
  }
}
```
